## Запуск

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate      # Linux, macOS
.venv\Scripts\activate         # Windows
pip install requests httpx
python task0.py
```

Время зависит от состояния сети, поэтому цифры при повторном запуске будут отличаться. Относительная разница между вариантами остаётся.
